# ΔΣΠ Study Set

Typing tests and study quizzes for Delta Sigma Pi pledges at the Theta Sigma chapter (UCF):

- **Mission statement** and **Rose of Deltasig** typing tests (Monkeytype-style, with WPM, accuracy and timestamped history)
- **Greek Letters**, **Executive Board 26'**, **Executive Board 25'** and **Pledge Classes** study modes, each with a study sheet, flashcards and a timed 20-question quiz

Scores and history are saved in each visitor's own browser.

Live site: https://pizzaparlorpenguin.github.io/dspstudyset/
